# 界面分页与现代化更新

日期：2026-09-21

## 技术方案

使用原生 Java 和 XML 布局，接入 Google 官方 Material Components 与 AndroidX。沿用现有配置、Root、推送、加解密和子配置实现，不迁移到 Compose，也不使用网页界面。

| 组件 | 版本与用途 |
|---|---|
| Material Components | 1.14.0，底部导航、按钮、表单、对话框、延时选项 |
| AppCompat | 1.7.1，工具栏与日夜主题 |
| RecyclerView | 1.4.0，目标和应用列表 |
| Android Gradle Plugin | 8.11.1 |
| Gradle | 8.13，使用仓库 Wrapper |
| Java / Android SDK | JDK 17、compileSdk 35、build-tools 35.0.1 |

最低系统版本仍为 Android 6（API 23），targetSdk 仍为 34。当前仓库根目录仅构建管理器，模块由用户从上游发布页获取。

## 页面划分

| 底部菜单 | 主要操作 |
|---|---|
| 目标 | 环境状态、添加目标、目标更多操作、推送并应用 |
| 脚本 | Gadget 表单或原始 JSON、脚本处理、选择脚本、保存与写入 |
| 日志 | 标签选择、实时采集、停止、清空和复制 |
| 工具 | 模块目录、Root 检查、文件和子配置导入、脚本加解密、命令与输出 |

底部分页复用已有页面实例，避免切换时丢失草稿和工具输出。详情页不显示底部菜单；从目标编辑页进入脚本配置时，返回路径保持为当前目标。

## 交互调整

- 工具栏、间距、输入框和按钮样式统一；支持浅色与深色主题。
- 目标显示应用图标、包名、启用状态和注入摘要，更多操作提供明确入口。
- 应用列表支持搜索、系统应用筛选和无匹配状态。
- 目标编辑按进程、延时、注入库、脚本和子进程分区；保存操作固定在底部。
- 延时快捷项可自动换行；长路径允许多行显示。
- 脚本表单按交互模式显示相关字段，保存直接采用当前编辑视图；同模式编辑保留高级 JSON 字段。
- 密钥输入默认遮挡，子配置提供的隐藏密钥不显示输入框。
- 移除自动注入 Toast 的设置和生成代码；明文直接加载，加密 loader 只负责解密、加载与日志。用户脚本自己的 Toast 保持原样。
- 日志标签改为直接选择；离开页面停止本次采集，保留有上限的显示缓冲区。停止操作只结束本次日志进程，不再按命令名停止其他日志客户端。
- 工具输出可折叠，执行检查后自动展开。

## 验证方法

在仓库根目录执行：

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

在仓库根目录执行现有核心逻辑自测：

```powershell
powershell -ExecutionPolicy Bypass -File selftest\run.ps1
```

配置回归测试覆盖：同模式编辑保留高级设置、切到 script 时清除网络字段和暂停选项、关闭自动重载时保留脚本参数、显式表单生成替换无效原始内容。

本轮构建、4 项配置回归测试、56 项核心逻辑自测均通过。新增用例检查管理器不产生 Toast、用户脚本 Toast 仍能执行、加载失败只写日志。Android Lint 为 0 个错误、30 个警告，警告涉及目标 SDK、资源和现有代码风格等。

已在 PLC110 / Android 15 真机检查四页切换、选中状态、Root 检查、工具输出保留、脚本草稿保留、表单到 JSON 同步、日志标签采集、详情页返回、应用搜索空状态，以及自动 Toast 开关已移除。

浅色、深色和 360dp 宽度下的页面均已截图检查。真机测试保持原有 1.15 倍字体，完成后恢复 1272 × 2800 分辨率、560dpi 与原来的浅色模式。测试期间没有推送或覆盖用户现有注入配置。本轮日志中没有新增管理器崩溃。

UI 验证不会替代在不同 Android 版本上对实际注入链路的回归测试。旧版已部署的 loader 需重新导入脚本或子配置才能替换，安装 APK 不会自动改写设备脚本。

## 第二轮视觉与文字排版

本轮保留四个分页，重新设计界面层级：正文使用 Noto Sans SC 常规字重，标题和操作使用中等字重。页面标题为 20sp，内容标题 15sp，正文 14sp，辅助信息 12sp，包名和日志 11sp；字号继续遵循系统字体缩放，不修改用户设置。

白色与浅灰承载主要内容，蓝色标记操作和选中项，绿色表示就绪状态。输入框采用浅底填充，按钮与弹窗使用较小圆角，工具操作使用统一细线图标。

说明按需查看：页面顶部问号提供整体说明，局部问号解释环境状态、交互模式、脚本处理、完整路径、锁定原因、注入延时和子进程行为。工具页把目录、su 和自定义命令折叠在高级设置中。

字体文件来自 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk/tree/main/Sans/SubsetOTF/SC)，按 [SIL Open Font License 1.1](licenses/NotoSansSC-OFL.txt) 分发。字体在 APK 中内置，启动时无需联网下载；完整中文字库会增加安装包体积。许可证和版权说明同时包含在 APK 的 assets/fonts 中。

已检查真机普通字体下的四页、应用选择、目标编辑、局部帮助与延时快捷项；使用 Android 15 模拟器和真机检查 360dp 宽度、深色主题和 1.6 倍字体。大字体按钮可随文字增高，真机测试后已恢复 1.15 倍字体、原分辨率与浅色主题。测试期间没有推送或改写真机注入配置。

本轮构建与 4 项配置回归测试通过，Android Lint 为 0 个错误、35 个警告。加解密、推送和子配置核心实现未在本轮修改。
